How this console fits the workflow

Scheduled Hermes jobs handle website rotation (T2) and weekly search (T3); the independent PDF intake writer queues its candidates in the shared Registry. T1 daily information checks improve facts, while T10 native acquisition review decides whether exact candidate versions can be activated. Use Runs for manual acquisition starts and run inspection, and Pipeline / reports to read saved business evidence. The biweekly report task (T4) reads approved Registry content; T5 performs the separate native review of the exact PDF; T6 sends that exact file only after formal PASS and delivery configuration. Job setup and execution happen in Hermes; this console shows the saved results and handles PDF intake.

Use Configuration to validate and version task settings, Runs to start or inspect acquisition and resume its frozen binding, Meetings to query saved meeting records, Pipeline / reports to inspect business evidence, and PDF Imports to preview and queue an intake batch. A scheduled or configured job is not proof it ran. A scheduler exit of zero, a source check, acquisition approval, formal PDF PASS and an actual send are separate evidence.

Current references: workflow and ownership, configuration and task profile, program and evidence contracts, deployment and review gates, acquisition review, formal PDF review.

Preview validates without saving. Save creates a new active version for subsequent new runs, subject to each role's overrides. Existing runs retain their frozen binding; Resume reuses it. Restore copies a selected version into a new version. Provider/model fields are recorded task settings; the actual Hermes provider/model identity is frozen in the separate per-run runtime snapshot.

Pipeline / reports
Refresh reads saved business evidence. Pending, partial or conflicting source evidence stays distinct from a passed source check; stale or unknown observations do not prove success. Scheduler completion records process exit, not source quality or approval. Acquisition approval activates eligible Registry candidates. Formal PDF PASS applies only to the exact reviewed report revision; sending is a later separate action and must be evidenced by delivery results.
